# IRAM — Full-Stack Intelligent Construction Material Lifecycle Platform
## منصة إدارة دورة حياة مواد البناء بالذكاء الاصطناعي (Full Stack System Architecture)

> **شعار المنصة:** "Every Material. Every Project. Smarter Decisions."  
> **الإصدار:** 2.0 (Enterprise Multi-Tenant SaaS)  
> **التقنيات:** React 18 + Vite + Tailwind CSS + Lucide Icons + Recharts (Frontend) | Node.js + Express REST API (Backend)

---

## 🏗️ 1. الفصل الكامل بين حسابات الشركات وحسابات الموردين (System Portals)

تم فصل النظام إلى بوابتين ومساري تسجيل ودخول مستقلين تماماً:

### أ. بوابة شركات الإنشاءات والمقاولات (Contractor Company Portal)
* **تسجيل الشركات:**
  * خطوة 1: البيانات الرسمية (اسم الشركة، السجل التجاري CR، الرقم الضريبي Tax ID، نوع المقاولة، المدينة).
  * خطوة 2: حساب مسؤول الشركة الأول (Company Admin).
  * خطوة 3: التحقق برمز OTP لتفعيل المستأجر (Tenant).
* **إدارة الصلاحيات والمشاريع (Company Admin & RBAC):**
  1. **إضافة المشاريع:** يستطيع مسؤول الشركة إنشاء مشاريع جديدة وتحديد ميزانياتها والجدول الزمني.
  2. **توزيع الأدوار للمشاريع:** تعيين كل مهندس على مشروع محدد:
     * **Project Manager (PM):** يرى فقط المشروع المسند إليه (مثل كمبوند المنصورة)، يتابع كميات الـ BOQ، ويوافق على النقل الداخلي للفائض.
     * **Site Engineer:** تسجيل الاستهلاك اليومي ورصد الهدر غير الطبيعي.
     * **Procurement Officer:** إدارة الـ RFQs ومقارنة العروض واختيار المورد وإصدار الـ PO والرد على الموردين.
     * **Warehouse Officer:** الاستلام الفعلي بالمخازن، فحص أذون الاستلام ضوئياً بالـ OCR، وتسجيل الفائض المتبقي.

---

### ب. بوابة مجتمع الموردين المستقلة (Supplier Community Portal)
* **تسجيل الموردين المعتمدين:**
  * تسجيل بيانات المصنع أو المورد التجاري، فئة المواد (حديد، أسمنت، خرسانة، مواسير، تشطيبات)، ومناطق الخدمة المغطاة، والسجل التجاري، والحساب البنكي.
* **تقديم العروض واستلام ردود الشركات:**
  1. **الاطلاع على طلبات التوريد (RFQs):** تظهر للمورد طلبات المقاولين الحقيقية الموافقة لتخصصه.
  2. **تقديم عروض الأسعار:** إدخال سعر الوحدة، تكلفة الشحن، مدة التسليم (Lead Time)، وشهادات الجودة والضمان.
  3. **استلام الردود والقرارات الرسمية:** قسم خاص **"My Quotations & Contractor Replies"** يعرض رد شركة المقاولات المباشر:
     * *حالة العرض:* (Accepted - PO Issued / Declined / Revision Requested).
     * *ملاحظات الشركة:* نص رسمي من مسؤول المشتريات (مثال: "تهانينا! تم اختيار عرضكم وتم إصدار أمر الشراء PO-0043").
     * *أمر الشراء (PO):* استعراض العقد وأمر الشراء الصادر للمورد فور قبوله.

## 🧠 2. موديول التنبؤ بالهدر بالذكاء الاصطناعي (AI Waste Prediction - FR-WP-01 to 10)
* حساب الهدر التقديري ونسبة الهدر المئوية ومقارنتها بالمعدل المرجعي (Baseline).
* تصنيف المخاطر آلياً: **Low / Medium / High**.
* تحديد أسباب الهدر (Contributing Factors) وتوليد توصيات فورية (مثل برمجيات قص الحديد BBS 1D).
* توثيق المراجعة الهندسية البشرية (Human Review & Audit Trail).
* محاكي تفاعلي لتجربة التنبؤ على أنشطة ومواد جديدة.

## ⚡ 3. طريقة تشغيل المشروع (Full-Stack Setup)

### 1. تشغيل الباك إند (Node.js API):
```bash
cd backend
npm install
npm start
```
* يعمل السيرفر على: `http://localhost:5000`

### 2. تشغيل الفرونت إند (React + Vite):
```bash
cd frontend
npm install
npm run dev
```
* تفتح الواجهة التفاعلية على: `http://localhost:3000`
