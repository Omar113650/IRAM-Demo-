0. IRAM — High-Level Use Case Diagram (المخطط الشامل لكافة أدوار المنصة)

يجمع كل الـ 7 Actors معاً: Super Admin • Company Admin • Project Manager • Site Engineer • Procurement Officer • Supplier • Warehouse Officer

1. Project Manager Use Case Diagram (مدير المشروع — النسخة المدمجة الشاملة)

تشمل: الـ BOQ، والموافقة على الطلبات، وفحص التوفر وتنبؤ النقص، وإدارة الفائض، ومنظومة تنبؤ الهدر بالذكاء الاصطناعي والمساعد الذكي (Chatbot)

2. Company Admin Use Case Diagram (أدمن الشركة — مركز الحوكمة والقرارات والمخازن)

تشمل: إدارة الصلاحيات، المشاريع والمخازن (Warehouses)، وسجل التدقيق (Audit Log)، وإعدادات الشركة، والرؤية الموحدة للمخزون والذكاء الاصطناعي

3. Supplier Partner Use Case Diagram (بوابة المورد — نفس التصميم المرفوع بالضبط)

تشمل: إدارة البروفايل، عروض الأسعار، أوامر الشراء، تحديث الشحنات، وتقارير وسجل الأداء

4. Procurement Engineer Use Case Diagram (مهندس المشتريات — الدورة التشغيلية الكاملة)

تشمل: استلام الطلبات، كتالوج المواد، إنشاء وتوجيه RFQs، مقارنة وتقييم العروض بالذكاء الاصطناعي، وإنشاء وتتبع أوامر الشراء واعتمادها

5. Site Engineer Use Case Diagram (مهندس الموقع — النطاق التشغيلي للمشروع)

تشمل: تقديم وتعديل طلبات المواد، فحص مخزون المشروع، تسجيل الاستهلاك الفعلي، والإبلاغ عن الفائض مع إنشاء مقترح التحويل تلقائياً

6. Warehouse Manager Use Case Diagram (مدير المخزن — الرقابة اللوجستية والمخزون)

تشمل: فحص واستلام الشحنات ومطابقتها بأوامر الشراء، صرف المواد للمشروعات، ضبط جرد المخزون، والتحويلات بين المخازن
